# Portfolio Streamlit — Arij Sghiri

## Lancer en local
pip install -r requirements.txt
streamlit run app.py

## Déployer (Streamlit Community Cloud)
1. Pousser ce dossier sur un dépôt GitHub public.
2. Aller sur https://share.streamlit.io, se connecter avec GitHub.
3. "Create app" > choisir le dépôt, la branche et `app.py` > Deploy.
